# Shell Scripting Lab - F.Y. B.Tech

This repository contains all my Linux shell scripting lab exercises and assignments completed during my First Year B.Tech coursework.

## 🛠️ Environment & Tools
* **OS:** Linux (Ubuntu / VirtualBox)
* **Shell:** GNU Bash (`/usr/bin/env bash`)
* **Editor:** nano / terminal

---

##  List of Experiments

| No. | Script Name | Description |
| :--- | :--- | :--- |
| 01 | `01_hello_linux.sh` | Basic echo statement to display text output. |
| 02 | `02_variables_demo.sh` | Demonstrates basic variable declaration and usage. |
| 03 | `03_user_input.sh` | Accepts simple user input using `read`. |
| 04 | `04_user_inputs_output.sh` | Formatted user input and prompt display. |
| 05 | `05_arithmetic_operations.sh` | Standard mathematical operations using `expr` / `$(( ))`. |
| 06 | `06_let_arithmetic.sh` | Performs arithmetic calculations using the `let` keyword. |
| 07 | `07_command_line_args_lister.sh` | Accepts and displays positional parameters (`$1`, `$2`, etc.). |
| 08 | `08_file_permissions_checker.sh` | Checks read/write/execute permissions of files in the current folder. |
| 09 | `09_factorial_calculator.sh` | Calculates factorial of a number using a `for` loop. |
| 10 | `10_multiplication_table.sh` | Generates multiplication tables using a `while` loop with regex validation. |
| 11 | `11_menu_calculator.sh` | Menu-driven calculator using `case` statements and zero-division checks. |
| 12 | `12_largest_of_three_numbers.sh` | Finds the maximum of 3 numbers using nested `if-else`. |
| 13 | `13_largest_of_n_numbers.sh` | Dynamic check to find the largest number among $N$ user inputs. |
| 14 | `14_sum_of_even_factorials.sh` | Calculates sum of factorials for even numbers within a given range. |
| 15 | `15_file_statistics_wc.sh` | Analyzes file statistics (lines, words, bytes, chars) using `wc` and interactive prompt. |
| 16 | `16_file_statistics_positional_arg.sh` | Analyzes file statistics using command-line positional parameters. |
